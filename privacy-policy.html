Globe Boss — Privacy Policy

Last updated: May 23, 2026

Globe Boss ("the extension") is a developer tool that helps users identify errors and issues on web pages they visit. This policy explains what the extension does and does not do with your data.

What we collect

Nothing is sent to any server. Globe Boss does not collect, transmit, store remotely, or sell any user data.

What the extension reads

To perform its function, Globe Boss reads the following from web pages you choose to inspect:

  • JavaScript errors and unhandled promise rejections
  • Browser console messages (errors and warnings)
  • Network request URLs, methods, status codes, and timing
  • HTML structure of the active page (for the on-demand audit feature)
  • Page load performance metrics

Where this data is stored

All captured information is held only in your browser's memory, for the lifetime of the open tab. Closing the tab or clicking "Clear" in the extension popup erases it. Nothing is written to disk, synced across devices, or transmitted off your machine.

Third parties

Globe Boss does not use analytics, advertising networks, tracking pixels, or any third-party services. It makes no outbound network requests of its own.

Permissions explained

  • activeTab — read the page you're currently on, only when you open the extension popup
  • scripting — inject the small script that listens for errors on the page
  • storage — remember your tab preferences locally (not currently used to store user data)
  • host_permissions — listen for errors on any site you visit; required because errors can happen on any URL

Children

Globe Boss is a developer tool not directed at children under 13.

Changes to this policy

If the extension's data practices ever change, this page will be updated and the version number of the extension will be incremented.

Contact

Questions about this policy can be sent to the developer through the Chrome Web Store listing's support link.
